# 系統設計文件（SDD）

本文件描述 MiniRecorder（mini錄音機）的設計目標、需求、資料模型、狀態機、主要流程
與設計決策。

---

## 1. 設計目標

1. **快速**：從多個入口（App、QS Tile、Widget）皆能在數秒內開始錄音。
2. **穩定**：背景與螢幕休眠時錄音不中斷，並妥善處理資源與異常。
3. **清楚**：錄音檔具備標題、標籤與要點，易於日後檢索與重聽。
4. **可控**：提供音效、靜音跳過、聲道與最長時間等可調整選項。
5. **簡潔**：以單一 Activity + Compose 導覽，降低結構複雜度。
6. **離線優先**：所有資料儲存於本機，不需網路。

## 2. 需求

### 2.1 功能需求（FR）

| 編號 | 需求 |
| --- | --- |
| FR-01 | 使用者可開始 / 暫停 / 繼續 / 停止錄音 |
| FR-02 | 錄音檔以 AAC/M4A 儲存，並記錄標題、時間、長度、大小、聲道 |
| FR-03 | 支援單聲道與立體聲（自動降級） |
| FR-04 | 可啟用降噪、回音消除、AGC |
| FR-05 | 可啟用靜音跳過並設定門檻與最短靜音長度 |
| FR-06 | 錄音中可即時標記要點 |
| FR-07 | 可瀏覽、搜尋、排序與標籤過濾錄音清單 |
| FR-08 | 可播放錄音，支援倍速、快轉 / 快退、要點跳轉 |
| FR-09 | 可新增 / 編輯 / 刪除要點，並在時間軸顯示 |
| FR-10 | 可維護標籤（新增 / 重新命名 / 上色 / 刪除） |
| FR-11 | 可匯入外部音訊檔 |
| FR-12 | 可分享與刪除錄音 |
| FR-13 | 可設定最長錄音時間並提供時間提醒 |
| FR-14 | 可自訂主題模式與色彩 |
| FR-15 | 支援 QS Tile 與桌面小工具快速錄音 |
| FR-16 | 錄音中可停止並捨棄（永久刪除）目前這段錄音 |

### 2.2 非功能需求（NFR）

| 編號 | 需求 |
| --- | --- |
| NFR-01 | 支援 Android 8.0（API 26）以上 |
| NFR-02 | 螢幕休眠時仍可持續錄音 |
| NFR-03 | 錄音過程中維持即時 UI 更新（計時、聲波） |
| NFR-04 | 妥善釋放 MediaCodec / MediaMuxer / AudioRecord 資源 |
| NFR-05 | 所有個資與音訊資料保留於本機，無網路傳輸 |
| NFR-06 | Pre-release 建置須啟用 R8 壓縮並以 Debug 金鑰簽署 |

## 3. 使用案例

| 使用案例 | 主要參與者 | 前置條件 | 主要流程 |
| --- | --- | --- | --- |
| UC-01 開始錄音 | 使用者 | 已授予麥克風權限 | 點擊錄音 → 啟動 FGS → 建立檔案與記錄 → 開始錄製 |
| UC-02 暫停 / 繼續 | 使用者 | 錄音中 | 送 PAUSE / RESUME Action → 更新狀態 |
| UC-03 標記要點 | 使用者 | 錄音中 | 送 MARK Action → 寫入 Marker |
| UC-04 停止並保存 | 使用者 | 錄音中 | 停止引擎 → 更新長度 / 大小 → 返回清單 |
| UC-05 播放錄音 | 使用者 | 有錄音檔 | 選取 → MediaController 播放 |
| UC-06 整理與檢索 | 使用者 | 有錄音檔 | 搜尋 / 排序 / 標籤過濾 / 編輯標籤 |
| UC-07 匯入音訊 | 使用者 | 有外部音訊 | OpenDocument → 複製並解析中介資料 → 寫入 DB |
| UC-08 快速錄音 | 使用者 | 已授予權限 | 點 Tile / Widget → 啟動 FGS |
| UC-09 捨棄錄音 | 使用者 | 錄音中 | 送 DISCARD → 停止引擎 → 刪除檔案與紀錄 |

## 5. 資料模型（ER）

```
┌────────────────────┐          ┌───────────────────────┐
│     recordings     │          │       markers         │
├────────────────────┤          ├───────────────────────┤
│ id (PK)            │◄────┐    │ id (PK)               │
│ title              │     └────│ recordingId (FK)      │
│ filePath           │          │ timestampMs           │
│ createdAt          │          │ note                  │
│ durationMs         │          │ createdAt             │
│ sizeBytes          │          └───────────────────────┘
│ channelCount       │
│ sampleRate         │          ┌───────────────────────┐
│ mimeType           │          │ recording_tags        │
└─────────▲──────────┘          ├───────────────────────┤
          │                     │ recordingId (PK,FK)   │
          │                     │ tagId (PK,FK)         │
          │        ┌────────────┴───────────────────────┘
          │        │
          │   ┌────┴──────────┐
          └───│     tags      │
              ├───────────────┤
              │ id (PK)       │
              │ name (unique) │
              │ colorHue      │
              └───────────────┘
```

關聯：

- `recordings` 1 ── N `markers`（刪除錄音時 CASCADE 刪除要點）
- `recordings` N ── N `tags`（透過 `recording_tags`，皆 CASCADE）

## 6. 狀態機

### 6.1 錄音狀態

```
          START
   ┌──────────────────► RECORDING ──PAUSE──► PAUSED
   │                       │   ▲                │
 IDLE                     │   └────RESUME──────┘
   │                       │
   │                       ├─ STOP / 逾時 / 錯誤 ─► IDLE（保存結果）
   │                       └─ DISCARD ───────────► IDLE（刪除結果）
   └───────────────────────┘
```

- `RecordingUiState` 欄位：`isRecording`、`isPaused`、`elapsedMs`、`amplitude`、
  `amplitudeHistory`、`title`、`recordingId`、`channelCount`、`markers`、`message`。
- 狀態集中於 `RecordingStateHolder`，以 `StateFlow` 對外發佈。

### 6.2 播放狀態

```
IDLE ──setMediaItem/prepare──► READY ──play──► PLAYING
  ▲                              ▲               │
  │                              └────pause──────┘
  └────────── stop / 清單清空 ───────────────────┘
PLAYING ──ENDED──► 停止位置更新（可 seekTo(0) 重播）
```

- `NowPlaying` 欄位：`recordingId`、`title`、`isPlaying`、`positionMs`、`durationMs`、`speed`。
- 播放位置由 `PlaybackController` 以 250 ms 週期更新。

## 8. UI 設計

### 8.1 導覽結構

- 單一 `MainActivity`，以 `AppNavHost` 管理。
- 頂層頁籤（底部導覽列，Fade Through 轉場）：`list`、`record`、`settings`。
- 次級頁面（Slide & Fade 轉場）：`display`（顯示設定）、`player/{id}`（播放）。
- 當 `isRecording` 為 true，會自動導覽至 `record` 頁。
- 有 `nowPlaying` 時，非播放 / 顯示頁面會顯示迷你播放列。

### 8.2 畫面清單

| 畫面 | 路由 | 主要內容 |
| --- | --- | --- |
| 錄音清單 | `list` | 搜尋、排序、標籤過濾、卡片清單、清單即時播放 / 暫停、匯入、空狀態 CTA |
| 錄音 | `record` | 狀態指示、計時器、聲波、控制按鈕、要點清單 |
| 設定 | `settings` | 聲道、音效、靜音跳過、錄音長度、標籤維護 |
| 顯示設定 | `display` | 主題模式、色票、色相滑桿 |
| 播放 | `player/{id}` | 標題、時間軸與標記、控制項、標籤、要點清單 |

### 8.3 設計原則

- **拇指熱區**：錄音主按鈕置中放大（76–80 dp），次要動作置於兩側。
- **觸覺回饋**：主要操作呼叫 `HapticFeedback`。
- **即時回饋**：狀態燈呼吸動效、即時聲波、等寬計時器。
- **無障礙**：互動元件皆提供 `contentDescription`。

## 9. 設計決策與取捨

| 決策 | 理由 | 取捨 |
| --- | --- | --- |
| 以 `AudioRecord` + `MediaCodec` 自製錄音引擎 | 可精細控制暫停、靜音跳過與即時振幅 | 需自行管理編碼與封裝生命週期 |
| 以 `ForegroundService` 錄音 | Android 背景限制下確保穩定 | 必須顯示常駐通知 |
| `RecordingStateHolder` 單例作為 Service↔UI 橋樑 | 避免 UI 綁定 Service，跨畫面共享狀態 | 需注意生命週期與重置 |
| 以 Media3 `MediaSessionService` 播放 | 支援背景播放與系統媒體控制 | 需額外處理控制器連線 |
| 以 Room 儲存中繼資料、檔案存於內部空間 | 查詢能力佳且結構化 | 檔案需透過分享匯出 |
| 以 DataStore 儲存偏好設定 | 非同步、型別安全 | 首次讀取需等待 |
| 小工具點擊以 `ACTION_QUICK_RECORD` 開啟 App 並錄音 | 行為一致（避免既有任務被喚起造成時而開、時而不開） | 每次都會開啟 App |
| 錄音引擎啟停移至背景執行緒（`audio-engine`） | 避免停止錄音時阻塞主執行緒 | 需加入單一背景執行緒與競態守衛 |
| 清單播放鈕反映播放狀態 | 可就地播放 / 暫停，操作直覺 | 需由 `NowPlaying` 衍伸輕量狀態以避免清單重組 |
| 導入 Baseline Profile | 改善冷啟動與首次互動效能 | 需裝置產生並維護 profile |
| 動態 HSL 產生主題色 | 無需多份資源即可自訂色彩 | 需自行控制對比度 |

## 10. 錯誤處理與邊界情況

- **麥克風初始化失敗**：顯示「無法初始化麥克風」，刪除未完成的記錄並停止服務。
- **立體聲不支援**：自動降級為單聲道並反映於 UI 與通知。
- **播放與錄音衝突**：錄音開始時若正在播放，會先中止播放；播放時若正在錄音則阻擋。
- **服務被系統終止**：`onDestroy` 以 `NonCancellable` 保存已錄製內容。
- **權限不足**：各入口檢查麥克風權限，導向 App 要求授權。
- **匯入失敗**：`importAudio` 回傳 null，UI 以 Toast 提示「匯入失敗」。
