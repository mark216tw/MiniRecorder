# 使用指南

本文件說明 MiniRecorder（mini錄音機）的安裝方式、權限需求與各項功能操作。

---

## 1. 安裝

### 1.1 取得安裝檔

可由 GitHub Release 頁面下載測試發行版本 `app-prerelease.apk`：

- `app-prerelease.apk` 為 **Pre-release 測試版本**，啟用 R8 壓縮並以 Debug 金鑰簽署。
- 此檔案僅供測試，**不建議用於正式環境或長期保存重要錄音**。

### 1.2 安裝步驟

1. 將 `app-prerelease.apk` 傳輸至 Android 裝置。
2. 於裝置「設定 → 應用程式 → 特殊應用程式存取權」允許來源安裝（允許安裝未知來源應用程式）。
3. 點擊 APK 檔案進行安裝。
4. 首次開啟時，依畫面指示授予麥克風權限。

> 系統需求：Android 8.0（API 26）以上，且裝置需具備麥克風。

---

## 2. 權限說明

| 權限 | 用途 |
| --- | --- |
| `RECORD_AUDIO` | 錄音（必要） |
| `POST_NOTIFICATIONS` | 顯示錄音中通知與提醒（Android 13+ 需動態授予） |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MICROPHONE` | 於前景服務中持續錄音 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 於前景服務中播放錄音 |
| `VIBRATE` | 錄音提醒時的震動回饋 |
| `WAKE_LOCK` | 螢幕休眠時仍持續錄音 |

若未授予麥克風權限，錄音頁面會顯示提示卡片與「授予權限」按鈕。

---

## 3. 介面總覽

應用程式底部有三個主要頁籤：

- **錄音檔**：錄音清單、搜尋、排序、標籤過濾、匯入音樂。
- **錄音**：開始 / 暫停 / 繼續 / 停止錄音、即時聲波、標記要點。
- **設定**：聲道、音效、靜音跳過、錄音長度與標籤維護。

播放時，畫面底部會顯示迷你播放列（Mini Player Bar），點擊可進入播放頁。

---

## 4. 錄音功能

### 4.1 開始錄音

1. 切換到「錄音」頁籤。
2. （可選）點擊標題右側的編輯圖示，設定自訂標題；留空則自動以時間命名。
3. 點擊中央的麥克風按鈕開始錄音。

畫面上方會顯示狀態（待機 / 錄音中 / 已暫停）、等寬計時器、目前設定摘要，
以及即時聲波視覺化。

### 4.2 暫停 / 繼續

錄音中點擊「暫停」按鈕可暫停；再次點擊「繼續」恢復錄音。暫停期間不計入錄音內容。

### 4.3 標記要點

錄音中點擊「標記」按鈕，會在當前時間點加入一個要點，並即時顯示於下方清單。
播放時這些標記會出現在時間軸上，並可快速跳轉。

### 4.4 停止錄音

點擊「停止」會結束錄音並將檔案寫入資料庫，自動返回清單。錄音檔儲存於應用程式內部
儲存空間（`files/recordings/REC_<時間戳>.m4a`）。

### 4.5 捨棄錄音

若不想保留目前這段錄音，點擊「捨棄」按鈕，於確認對話框按下「捨棄」後，會停止錄音並
**永久刪除該檔案與資料庫紀錄**（無法復原）。

### 4.6 最長錄音與提醒

於「設定 → 錄音長度」可設定最長錄音時間（30～180 分鐘，以 30 分鐘為級距）。
接近上限的前 10 / 5 / 3 分鐘會發出通知、提示音與震動提醒；到達上限會自動停止。

## 5. 錄音檔清單

### 5.1 搜尋與排序

- 於頂端搜尋欄以標題關鍵字搜尋。
- 點擊右側排序圖示，可選擇：最新優先 / 最舊優先 / 時間最長 / 標題排序。

### 5.2 標籤過濾

點擊錄音卡片上的標籤可將其加入過濾條件（需同時符合所有已選標籤）；上方會顯示已選
標籤晶片，可個別移除或「清除全部」。

### 5.3 播放與開啟

- 點擊卡片右側的播放按鈕可直接播放（背景播放）。
- 點擊卡片本身進入播放頁。
- 錄音進行中時，清單會隱藏正在錄音的項目，且暫停播放。

### 5.4 匯入音樂

點擊右上角「匯入音樂」圖示，或空狀態的「匯入音樂」按鈕，可透過系統文件選擇器
匯入外部音訊檔。系統會嘗試讀取標題與長度等中介資料。

---

## 6. 播放功能

進入播放頁後可使用：

- **播放 / 暫停**：中央主按鈕。
- **倍速播放**：0.5x、0.75x、1.0x、1.25x、1.5x、2.0x。
- **快退 / 快進 10 秒**。
- **上一 / 下一要點跳轉**。
- **時間軸與標記視覺化**：拖曳滑桿可跳轉，時間軸上以紅色刻度顯示標記點。
- **標籤選擇**：於播放頁直接為該錄音勾選 / 取消標籤。
- **要點清單**：可新增、編輯與刪除要點，點擊要點可跳轉至對應時間。
- **分享**：透過系統分享選單分享檔案。
- **刪除**：刪除錄音（同時刪除檔案，無法復原）。

## 7. 設定

| 區段 | 項目 | 說明 |
| --- | --- | --- |
| 聲道 | 單聲道 / 立體聲 | 立體聲於部分裝置可能自動降級為單聲道 |
| 音效 | 降噪 / 回音消除 / AGC | 使用 `VOICE_COMMUNICATION` 音訊來源 |
| 靜音跳過 | 開關、靜音門檻、最短靜音長度 | 錄音時略過靜音片段 |
| 錄音長度 | 最長錄音時間、啟用時間提醒 | 30～180 分鐘 |
| 標籤維護 | 新增 / 編輯 / 刪除 / 上色 | 供錄音與清單過濾使用 |

## 8. 快速入口

### 8.1 快速設定磚（QS Tile）

於 Android 快速設定面板新增「快速錄音」磚，點擊即可切換錄音狀態。若尚未授予麥克風
權限，會開啟應用程式要求授權。

### 8.2 桌面小工具（Widget）

將「錄音小工具」加入桌面，小工具採響應式尺寸（2×1 與精簡尺寸），整張小工具可點擊，
點擊即快速開始錄音。

### 8.3 顯示設定

於錄音檔清單右上角的調色盤圖示進入「顯示設定」，可調整：

- 顯示模式：系統 / 淺色 / 深色。
- 主題色彩：預設色票（藍 / 青綠 / 綠 / 琥珀橙 / 玫瑰粉 / 紫）或色相滑桿自訂。

## 9. 常見問題（FAQ）

**Q：為什麼錄音時通知列一直顯示？**
A：錄音以前景服務執行，需顯示常駐通知以符合 Android 規範，並確保背景錄音穩定。

**Q：為什麼鎖定螢幕後仍可錄音？**
A：應用程式於錄音期間持有 WakeLock，可在螢幕休眠時持續運作，並於最長時間或手動停止時釋放。

**Q：為什麼立體聲設定沒有生效？**
A：部分裝置不支援 `CHANNEL_IN_STEREO`，或無法同時套用音效，系統會自動降級為單聲道。

**Q：錄音檔在哪裡？如何取出？**
A：檔案儲存於應用程式內部儲存空間，可透過播放頁的「分享」功能匯出至其他應用程式。

**Q：這是正式版本嗎？**
A：`app-prerelease.apk` 為 Pre-release 測試版本，以 Debug 金鑰簽署，僅供測試。

---

## 10. 解除安裝

於裝置「設定 → 應用程式 → mini錄音機 → 解除安裝」。解除安裝會一併移除應用程式
內部儲存空間中的錄音檔，請先透過分享功能備份重要錄音。
